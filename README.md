# RICOCHET

Чертёжная песочница упругих ударов. Один мяч, четыре стены, рогатка и бесконечные траектории — всё в монохроме, без цвета и без зависимостей.

**▶ Играть:** https://seeeeeyou-glitch.github.io/Ricochet/

Один HTML-файл: canvas 2D + WebAudio, без библиотек, без сборки. Открыл — играешь.

## Управление

- **ЛКМ** по мячу — тяни и отпускай (рогатка)
- **ПКМ** — нарисовать стену; короткий правый клик по стене удаляет её
- **G** — показать/скрыть призрак прошлого броска (эталон для сравнения)
- **Esc** — закрыть панели

## Что внутри

- физика с двумя слоями трения и честным коэффициентом восстановления
- память-чертёж: траектории выцветают сами, как тушь на кальке
- мяч-инвертор через `globalCompositeOperation: difference`
- ноль `shadowBlur` — свечения нет, кадр не проседает

Монохром. Один сигнальный прибор. Ноль украшений ради украшений.
